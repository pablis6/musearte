# Musearte

Este proyecto forma parte del programa Accelerate, es un sitio web que simula la App de musearte, es unicamente un mockup minimamente funcional. A continuación se detallan los archivos y su propósito.

## Estructura del Proyecto

```
miusearte
├── css
│   └── style.css          # Estilos CSS para el proyecto
├── js
│   └── script.js         # Código JavaScript para la interactividad
├── pages
│   ├── about.html        # Página con información sobre la empresa
│   ├── contact.html      # Página con formulario de contacto
│   ├── portfolio.html     # Página que muestra trabajos anteriores
│   └── services.html     # Página que detalla los servicios ofrecidos
├── index.html            # Página principal del proyecto
└── README.md             # Documentación del proyecto
```

## Instalación

1. Clona el repositorio en tu máquina local.
2. Abre el archivo `index.html` en tu navegador para ver el sitio en acción.

## Uso

Navega a través de las diferentes páginas utilizando los enlaces proporcionados en la página principal. Cada página contiene información relevante sobre la empresa y sus servicios.
